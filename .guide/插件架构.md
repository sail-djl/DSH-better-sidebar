```

│                 DSH web host                     │

│  ┌───────────────────────────────────────────┐  │
│  │          better-sidebar (client half)     │  │
│  │  src/client/index.tsx → apply(ctx)       │  │
```

## Service API（供消费插件使用）

```typescript
// 消费插件 import
import type {} from 'dsh-better-sidebar'  // 触发 ctx.betterSidebar 类型合并

export const inject = ['betterSidebar']

export function apply(ctx: Context): void {
  // 注册 tab
  ctx.effect(() =>
    ctx.betterSidebar.registerTab({
      id: 'my-plugin:db',
      title: 'Database',
      icon: <DbIcon />,
      order: 50,
      component: ({ scope }) => <DbView sessionId={scope.sessionId} />,
    })
  )

  // 注册文件预览器
  ctx.effect(() =>
    ctx.betterSidebar.registerFileViewer({
      id: 'my-plugin:csv',
      exts: ['csv'],
      fetchStrategy: 'custom',
      load: async (path, scope) => parseCsv(await fetchCsvBytes(scope, path)),
      component: ({ customData, path }) => <CsvGrid data={customData} path={path} />,
    })
  )
}
```

## 构建架构

```
src/ → tsc (类型检查 + .d.ts 生成) → tsdown (bundle → lib/)
```

- `tsdown.config.ts` 定义 client bundle purity 门（禁止 value-import `@dsh-external/*`）
- `tsconfig.build.json` 仅编译 host 半
- client 半由 tsdown 单独 bundle

## 装载流程

```
profile/package.json#dsh.profile.bundles 含 'dsh-better-sidebar'
  ↓
cordis.patch.yml → - insert: - id: better-sidebar / name: 'dsh-better-sidebar'
  ↓
Loader resolve 'dsh-better-sidebar' → node_modules/dsh-better-sidebar
  ↓
src/index.ts → apply(ctx) → 注册路由 + 工具 + 提供服务
src/client/index.tsx → apply(ctx) → 注册 tab + viewer + 提供 client 服务
```
